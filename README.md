# E-Portfolio (AI + Detection)

Modern React portfolio template with AI and computer vision focus.

## Features
- React 18 + Vite
- Tailwind CSS
- Framer Motion for animation
- Professional sections: About, Featured Projects, Capabilities, Contact
- AI/Detection-themed portfolio cards

## Setup
1. Install Node.js (>=18) and npm.
2. Run `npm install`.
3. Start dev server: `npm run dev`.
4. Build for production: `npm run build`.

## Customization
- Update details in `src/App.jsx`
- Add projects to `projects` array
- Add real links and deployment URLs

## Notes
This repository was scaffolded with tools disabled or missing in editor, so run npm install first after installing Node/npm.
